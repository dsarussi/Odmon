## תקציר מנהלים

מערכת **ODMON** היא מערכת אוטומטית המחברת בין מערכת **עודכנית** (Odcanit) — מערכת ניהול התיקים של המשרד — לבין פלטפורמת **מאנדיי** (Monday.com), שמשמשת לניהול משימות ומעקב שוטף.

**בשורה אחת:** כל תיק שנפתח בעודכנית מופיע אוטומטית במאנדיי תוך מספר ימי עסקים, ונשאר מעודכן באופן שוטף — בלי צורך בהקלדה ידנית.

### מה המערכת עושה?

```
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│   ✦  פותחת פריטים חדשים במאנדיי עבור כל תיק שנפתח בעודכנית             │
│   ✦  מעדכנת מידע באופן אוטומטי — שמות, תאריכים, סכומים, סטטוסים       │
│   ✦  שומרת על סנכרון שוטף בין שתי המערכות                              │
│   ✦  מפעילה התראות כשיש עדכון בדיונים                                  │
│   ✦  מאפשרת אישור או דחייה של הגעה לדיון ישירות מתוך מאנדיי            │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### מה לא צריך לדאוג בנוגע אליו?

- **אין צורך לעדכן נתונים ידנית** — הנתונים מתעדכנים מעודכנית.
- **אין צורך ביצירת פריטים ידנית** — כל תיק מופיע אוטומטית.
- **אין צורך בידע טכני** — המערכת שקופה לחלוטין למשתמש.

### 1.2 שלב 1 — פתיחת תיק בעודכנית

התהליך מתחיל כאשר תיק חדש נפתח במערכת **עודכנית**.
ברגע שהתיק נפתח שם — מערכת ODMON מזהה אותו באופן אוטומטי.

> **שימו לב:** אין צורך לעשות דבר נוסף. אין כפתור ללחוץ. אין טופס למלא. המערכת מזהה את התיק לבד.

<br/>

### 1.3 שלב 2 — תקופת הצינון (3 ימי עסקים)

לאחר פתיחת התיק בעודכנית, המערכת ממתינה **3 ימי עסקים ישראליים** לפני שהתיק מופיע במאנדיי.

**למה?**
תקופת הצינון מאפשרת לוודא שהתיק יציב, שכל הנתונים הבסיסיים הוזנו, ושלא מדובר בתיק שייסגר מיד.

**אילו ימים נספרים?**

```
ימים שנספרים:    ראשון  │  שני  │  שלישי  │  רביעי  │  חמישי
                  ✔       ✔       ✔         ✔         ✔

ימים שלא נספרים:  שישי  │  שבת
                   ✘       ✘
```

<br/>

### 1.4 שלב 3 — יצירת הפריט במאנדיי

לאחר תום תקופת הצינון, המערכת יוצרת **פריט חדש** בלוח (Board) המרכזי במאנדיי.

הפריט נוצר עם כל המידע שקיים בעודכנית, כולל:

- שם התיק (שם בעל הפוליסה או שם התובע)
- מספר תיק
- מספר לקוח
- תאריכים (פתיחה, אירוע, דיון)
- פרטי קשר (טלפון, דוא"ל, כתובת)
- סכומים כספיים
- סטטוס התיק: **"חדש"**
- סוג מסמך (כתב הגנה / כתב תביעה)
- ומידע רב נוסף

> **הפריט נוצר באופן מלא ומוכן לעבודה** — כל מה שקיים בעודכנית ישוקף אוטומטית.

<br/>

### 1.5 שלב 4 — סנכרון שוטף

לאחר היצירה הראשונית, המערכת ממשיכה לעקוב אחר שינויים בעודכנית ולעדכן את מאנדיי באופן אוטומטי.

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│   תדירות הסנכרון: כל ~20 דקות                         │
│                                                        │
│   מה מתעדכן?                                           │
│   ● שינוי בשם צד                                       │
│   ● שינוי סטטוס התיק (פתוח / סגור / תקוע)             │
│   ● עדכון תאריכי דיון                                  │
│   ● שינוי סכומים                                       │
│   ● עדכון פרטי קשר                                     │
│   ● עדכון שם שופט, בית משפט, עיר                       │
│   ● שינוי הערות                                         │
│   ● כל שדה אחר שמשתנה בעודכנית                         │
│                                                        │
└────────────────────────────────────────────────────────┘
```

> **חשוב:** הסנכרון הוא **חד-כיווני** — מעודכנית למאנדיי. אם תשנו ערך במאנדיי ידנית, ייתכן שהוא יוחלף בסנכרון הבא בערך שמגיע מעודכנית.

### 1.7 שלב 6 — עדכוני דיונים והתראות

כאשר מוזן מידע על דיון בעודכנית, המערכת מעדכנת במאנדיי:

- **תאריך הדיון**
- **שעת הדיון**
- **שם השופט**
- **שם בית המשפט**
- **עיר בית המשפט**
- **סטטוס הדיון** (פעיל / מבוטל / הועבר)

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  🔔 התראות וואטסאפ                                                 │
│  ──────────────────                                                 │

│  אוטומטית בוואטסאפ — באמצעות אוטומציות שמוגדרות                    │
│  בתוך מאנדיי עצמו.                                                 │
│                                                                     │
│  ההתראה נשלחת רק כאשר יש שם שופט ועיר בית משפט —                    │
│  כדי למנוע הודעות עם מידע חלקי.                                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.8 שלב 7 — אישור הגעה לדיון

זוהי הפעולה היחידה שמתבצעת **מתוך מאנדיי חזרה לעודכנית**:

```
                    ╔══════════════════════════╗
                    ║  עמודת "אישור הגעה"       ║
                    ║  במאנדיי                  ║
                    ╠══════════════════════════╣
                    ║                          ║
                    ║  ● מאשר הגעה             ║
                    ║  ● לא מאשר הגעה          ║
                    ║                          ║
                    ╚════════════╤═════════════╝
                                │
                                ▼
                    ╔══════════════════════════╗
                    ║  המערכת רושמת את          ║
                    ║  ההחלטה בעודכנית          ║
                    ╚══════════════════════════╝
```

כאשר משתמש בוחר **"מאשר הגעה"** או **"לא מאשר הגעה"** בעמודה המתאימה במאנדיי — המערכת רושמת את ההחלטה באופן אוטומטי בעודכנית.

> **שימו לב:** זוהי הפעולה היחידה שעוברת מהמשתמש במאנדיי חזרה למערכת עודכנית.

<br/>

### 1.9 הערות שנכתבות אוטומטית

עמודת **"הערות"** במאנדיי מסונכרנת ישירות מעודכנית.
כל הערה שנרשמת בתיק בעודכנית — תופיע גם במאנדיי.

> הערות אלו הן לקריאה בלבד מבחינת הסנכרון — אם תוסיפו הערה ידנית במאנדיי, היא עלולה להימחק בסנכרון הבא.

## פרק 6: שאלות נפוצות (FAQ)
## ═══════════════════════════════════════

<br/>

**ש: פתחתי תיק בעודכנית ולא רואה אותו במאנדיי. מה קורה?**
> ת: התיק עובר תקופת צינון של 3 ימי עסקים. הוא יופיע אוטומטית לאחר מכן. אם עברו יותר מ-5 ימי עסקים — פנו לדור.

---

**ש: שיניתי משהו בעודכנית. מתי זה יתעדכן במאנדיי?**
> ת: השינוי ישתקף במאנדיי בדרך כלל תוך **20 דקות** לכל היותר.

---

**ש: אני רוצה לשנות סטטוס של תיק במאנדיי. זה אפשרי?**
> ת: אפשרי טכנית, אבל **לא מומלץ**. הסטטוס מגיע מעודכנית ויידרס בסנכרון הבא. שנו את הסטטוס בעודכנית.

---

**ש: עמודה מסוימת ריקה. מה לעשות?**
> ת: בדקו אם המידע קיים בעודכנית. אם כן — הוא יתעדכן בסנכרון הבא. אם לא — הזינו אותו בעודכנית.

---

**ש: מה עושים אם המערכת לא עובדת?**
> ת: **לא לנסות לתקן.** פנו לדור או לצוות מאנדיי. המערכת תתאושש אוטומטית, ולא יאבד מידע.

---

**ש: איך אני מאשר הגעה לדיון?**
> ת: בעמודת **"אישור הגעה"** במאנדיי — בחרו **"מאשר הגעה"** או **"לא מאשר הגעה"**. ההחלטה נרשמת אוטומטית בעודכנית.

---

**ש: האם אפשר לעבוד רק עם מאנדיי בלי עודכנית?**
> ת: לא. עודכנית היא מערכת המקור. מאנדיי משקפת את המידע ומוסיפה כלי ניהול — אבל המידע חייב להיות מוזן בעודכנית.

---

**ש: האם המערכת עובדת בסופי שבוע?**
> ת: המערכת פועלת 24/7, אבל תקופת הצינון סופרת רק ימי עסקים (ראשון עד חמישי). תיקים שנפתחו בשישי או שבת ייספרו מיום ראשון.

---

**ש: מה קורה אם עודכנית לא זמינה?**
> ת: הסנכרון ימתין עד שעודכנית תחזור לפעולה, ואז ישלים את כל העדכונים. לא יאבד מידע.

---

**ש: אני מקבל התראת וואטסאפ. מאיפה זה מגיע?**
> ת: ההתראות נשלחות דרך **אוטומציות של מאנדיי** כאשר מתעדכן תאריך דיון. זה חלק מהמערכת המשולבת.

---

**ש: מה ההבדל בין "מבוטל" ל"הועבר" בעמודת הדיון?**
> ת: **"מבוטל"** — הדיון בוטל לחלוטין. **"הועבר"** — הדיון הועבר לתאריך אחר (התאריך החדש יופיע בעמודת תאריך הדיון).
